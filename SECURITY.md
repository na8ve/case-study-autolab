# Security

Please report a vulnerability privately to **dev@na8ve.com**, not in a public
issue. Say what you found, how to reproduce it, and what it lets someone do.
We will reply within a few working days.

In scope: this repository's code, including the approval step that gates
changes to the running lab and the way the lab sends readings to na8ve.com.

If an ingest key or token of yours may have leaked, revoke it at
na8ve.com/account first.
